# Contributing

Spotted a wrong price, a closed venue, or a dead menu link? Open a
[price correction issue](../../issues/new?template=price-correction.yml).
One rule: every correction needs a source URL from the venue itself (its
website, menu, rate card or booking system). That is the same standard the
data is held to, so a report without a source cannot be accepted, however
plausible it is.

Pull requests against the data files are welcome for typos in the docs, but
price changes only land through the source-of-truth pipeline behind
[marbellawire.com](https://marbellawire.com), so for figures an issue is the
faster path. The repo is regenerated each season; hand-edits to the CSV/JSON
would be overwritten.
